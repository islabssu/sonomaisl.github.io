Detecting Diabetic Retinopathy from Retinal Images

An embedded computer vision system for automated detection of diabetic retinopathy from retinal images.

← Back to Research

Built an embedded computer vision system for automated detection of diabetic retinopathy from retinal images, targeting low-cost deployment in resource-constrained settings.

Completed as Parshva Vora's MS thesis, Detecting Diabetic Retinopathy using Embedded Computer Vision (December 2019). A convolutional neural network was trained and cross-validated on roughly 88,000 labeled retinal images from the Kaggle/EyePACS dataset, reaching up to 76% classification accuracy. The work was published in Applied Sciences (2020).
